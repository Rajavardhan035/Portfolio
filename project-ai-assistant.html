Desktop AI Voice Assistant

A hands-free, intelligent desktop assistant built in Python that responds to spoken voice commands. It automates local application launches, fetches live search results, controls multimedia playback, and synthesizes natural voice responses.

Technologies & Libraries Used

Python SpeechRecognition pyttsx3 (TTS) PyAudio OS & Subprocess

Key Features

  • Offline Speech Synthesis: Uses `pyttsx3` for instant, latency-free text-to-speech audio feedback.
  • Voice Command Parsing: Captures audio input via microphone using Google Speech API integration.
  • App & System Automation: Launches Notepad, Chrome, Calculator, VS Code, and system utilities on command.
  • Web Querying: Performs instant Wikipedia summaries, YouTube video plays, and Google searches.

System Architecture

The architecture operates on an event-driven loop. The microphone listener captures acoustic waves, converts them into text strings via `SpeechRecognition`, parses command intents using keyword routing, triggers target system calls, and speaks back status notifications.
