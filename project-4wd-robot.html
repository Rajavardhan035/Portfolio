Smart Home Assistant Robot (4WD)

A custom-built 4-wheel-drive (4WD) robotic platform controlled by a Raspberry Pi single-board computer. Integrated with ultrasonic distance sensors, L298N motor drivers, and Python GPIO control scripts for real-time indoor navigation and obstacle avoidance.

Hardware & Tech Stack

Raspberry Pi 4 Python RPi.GPIO HC-SR04 Ultrasonic Sensor L298N Motor Driver

Key Features

  • Autonomous Obstacle Avoidance: Continuous ultrasonic ping loops measure forward clearances and steer the robot away from walls.
  • PWM Motor Speed Control: Pulse Width Modulation controls individual wheel speeds for smooth turn arcs.
